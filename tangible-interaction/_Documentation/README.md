# Extrality Tangible - Documentation

There are several types of ESP32 boards available in the Extrality Lab.

Each folder contains the documentation and pinout for the differnet ESP32 models. The links for official documentation are below:

- [ESP32-WROOM-32E Things](https://learn.sparkfun.com/tutorials/esp32-thing-plus-hookup-guide/all)
- [ESP32-S2 Things Plus](https://learn.sparkfun.com/tutorials/esp32-s2-thing-plus-hookup-guide/all)
- [ESP32-S3 DevKitC-1](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/index.html)
- [ESP32-S3 Zero](https://www.waveshare.com/wiki/ESP32-S3-Zero)
