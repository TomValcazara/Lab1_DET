# Basic - Examples

This folder contains examples of basic connections with sensors with ESP32.

Read more on electronics and working examples here:
- [Freenove Starter Kit for ESP32-S3](https://github.com/Freenove/Freenove_Ultimate_Starter_Kit_for_ESP32_S3/blob/main/C/C_Tutorial.pdf) - Note that it uses ESP32-S3, not ESP32-S2 board.
- [Arduino Project Book](https://archive.org/download/arduino_projects_book/arduino_projects_book.pdf) - Note that it does not use ESP32, but simpler Arduino boards. Physical copies of this book are also available at the lab.
